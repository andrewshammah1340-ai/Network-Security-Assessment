# Wireshark Packet Analysis

This folder contains packet captures from three network traffic experiments.

## ICMP
Used ping to observe network requests and replies.

## DNS
Used google.com to observe DNS name resolution.

## TCP
Used curl to connect to example.com and observe the TCP three-way handshake:

- SYN
- SYN-ACK
- ACK

The original packet capture files are included in this folder.
